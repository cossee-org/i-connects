{% comment %} The evidence dialog: where evidence is both read and edited. One dialog serves the whole Completion block. An assignee's evidence for their part is one note and a list of links (up to ``evidence_limit``). Either may be empty. The dialog shows the note on top and the links under it as a table, in both of its modes: view Opened by View evidence in a Done cell (task_evidence_line.html) with a ``view-evidence`` window event whose detail fills it in: name whose part, for the title ("Bob", or "your part") evidence {links: [...], note: "..."} updated when it last changed, as display text, or "" own whether it is the viewer's own part canEdit whether the viewer may change it now (their own part, done, not yet reviewed or verified) Each row of the table numbers a link, shows it in full so the reader sees where it really goes, and has its own Open (a new tab, without the opener or the referrer). A link to another host gets an External tag, and when any has one the dialog carries the same notice as the site's "Leaving i-CONNECTS" dialog (base.html), judged the same way: a different host from this page is leaving, the same host is not. Open is a plain link rather than one marked data-external-link: this dialog already gave the warning, so it is not asked a second time. With ``canEdit``, Add / Edit evidence switches it to edit mode; on the viewer's own part once reviewed or verified, it says instead that unticking Done is the way to change it. edit The same layout as a form: the note as a text box on top, the links as a table of link fields with Remove on each row, and Add another link under it (switched off at the limit). It starts from the viewer's saved evidence each time (``my_state.own_evidence``, kept from an earlier mark they may since have undone), with one empty link row when they have none, so Cancel discards any change: back to view mode when it came from there, closed when it did not. Opened straight in this mode by an ``open-evidence`` window event, from the viewer's own Done tick or the plain layout's Mark my part done button. Saving posts the note and one ``evidence_url`` per row, in order, with ``evidence_list`` marking the post as carrying evidence even with no rows (forms.EvidenceListForm). It replaces what was there; clearing the note and removing every link clears it. Blank rows are dropped. Which endpoint it posts to is decided when the block renders, since the block is swapped after every change: not done yet "Mark done": tasks:complete, marking the part done and saving the evidence together. done "Save evidence": tasks:evidence. A refusal (a link that is not http/https, too many links, a note too long, or evidence frozen by a review) comes back as a 400 whose text — naming the row, as "Link 2: …" — is shown above the buttons. The edit mode is only rendered for an assignee (``my_state``). Who sees the evidence is decided before this point: View evidence is only drawn for the assignee, the task's reviewers and its Leads.
