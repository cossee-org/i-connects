{% comment %} The assignee's evidence dialog, in the app's standard modal (the same shape as task_member_type_modal.html). It opens on an ``open-evidence`` window event, from the viewer's own Done tick, the plain layout's Mark my part done button, or Add / Edit evidence in their Done cell. It does one of two things, decided when the block renders, since the block is swapped after every change: not done yet "Mark done": posts tasks:complete with the evidence, so the part is marked done and the evidence saved together. done "Save evidence": posts tasks:evidence, changing it (empty fields clear it). Only offered while the part is not yet reviewed or verified (``s.can_edit_evidence``). Both fields are optional. The fields start filled with the viewer's own evidence, kept from an earlier mark they may since have undone. A refusal (a link that is not http/https, or evidence frozen by a review) comes back as a 400 whose text is shown above the buttons. Who sees the evidence is said in the dialog, because it is not everyone on the project: the task's reviewers and its Leads. Expects ``task``, ``my_state`` (the viewer's own assignee state), ``my_done`` and ``pane_mode``. {% endcomment %}
