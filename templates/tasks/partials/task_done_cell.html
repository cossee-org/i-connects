{% comment %} The Marked Done cell of one completion-matrix row: the mark, its date, and the Lead's buttons for setting or clearing it. Expects ``s`` (one entry of views._task_status_context's assignee_states) and ``task``. Buttons swap #task-status-block, the same target every other completion action uses. A mark set for an assignee by a Lead is named here, so the matrix does not read as if they had claimed it themselves. The mark itself belongs to the assignee, who sets it from the pane's top bar; ``s.can_mark_done`` is a Lead-only borrow of that action, per row, for recording a mark someone never clicked or clearing one set in error. It posts by member, not by TaskLog, so it works on a row whose entry has yet to be seeded — the service creates one. It is false once the task is marked completed, when every mark on the task freezes until a Lead marks it not complete again. {% endcomment %}
