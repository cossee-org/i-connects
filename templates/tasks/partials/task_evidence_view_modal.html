{% comment %} The evidence viewer: the list of items an assignee attached to their done part, shown before anyone follows a link. One dialog serves the whole Completion block; it opens on a ``view-evidence`` window event (from View evidence in a Done cell, task_evidence_line.html) whose detail fills it in: name whose part, for the title ("Bob", or "your part") items the evidence, a list of {url, note} in the assignee's order; either may be "" (an item has a link, a note, or both) updated when the evidence was last changed, as display text, or "" own whether it is the viewer's own part canEdit whether the viewer may change it now (their own part, done, not yet reviewed or verified) Each item is numbered, its link shown in full so the reader sees where it really goes, with its own Open link (a new tab, without the opener or the referrer) and its note under it. A link to another host gets an External tag, and when any item has one the dialog opens with the same notice as the site's "Leaving i-CONNECTS" dialog (base.html), judged the same way: a different host from this page is leaving, the same host is not. The Open links are plain links rather than ones marked data-external-link: this dialog already gave the warning, so it is not asked a second time. On the viewer's own part it is also where they change their evidence: Add evidence / Edit evidence closes this dialog and opens the evidence dialog (task_evidence_modal.html). Once the part is reviewed or verified it says instead that unticking Done is the way to change it. Who sees it is decided before this point: the button that opens the dialog is only drawn for the assignee, the task's reviewers and its Leads. {% endcomment %}
