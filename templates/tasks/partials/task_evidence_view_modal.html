{% comment %} The evidence viewer: what an assignee attached to their done part, shown before anyone follows it. One dialog serves the whole Completion block; it opens on a ``view-evidence`` window event (from View evidence in a Done cell, task_evidence_line.html) whose detail fills it in: name whose part, for the title ("Bob", or "your part") url the evidence link, "" when there is only a note note the assignee's note, "" when there is none updated when the evidence was last set, as display text, or "" own whether it is the viewer's own part canEdit whether the viewer may change it now (their own part, done, not yet reviewed or verified) On the viewer's own part it is also where they change their evidence: Add evidence / Edit evidence closes this dialog and opens the evidence dialog (task_evidence_modal.html). Once the part is reviewed or verified it says instead that unticking Done is the way to change it. The link is shown in full, so the reader sees where it really goes. A link to another host gets the same notice as the site's "Leaving i-CONNECTS" dialog (base.html), judged the same way: a different host from this page is leaving, the same host is not. Open link opens it in a new tab, without passing the opener or the referrer. It is a plain link rather than one marked data-external-link: this dialog already gave the warning, so it is not asked a second time. Who sees it is decided before this point: the button that opens the dialog is only drawn for the assignee, the task's reviewers and its Leads. {% endcomment %}
