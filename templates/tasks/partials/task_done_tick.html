{% comment %} The Done tick box of one completion-table row — ticked when the assignee's part is marked done, unticked when not. Ticking marks it; unticking undoes it. Expects ``s`` (one entry of views._task_status_context's assignee_states) and ``task``; it swaps #task-status-block, the target every completion action uses. Who may tick it is who could before: an assignee for their own part (``s.is_viewer``, through the self-mark endpoints), and a Lead for anyone else (``s.can_mark_done``, posting by member so a row with no entry yet still works). Everyone else sees it read-only. An assignee ticking their own part opens the evidence dialog (task_evidence_modal.html), which does the marking, so they can attach a link as they do; unticking undoes it straight away. A Lead ticking for someone else attaches no evidence: that is the assignee's to give. Once the task is marked completed, the marks a Lead sets for others freeze; an assignee's own box stays live, so whoever had not ticked when the Lead closed it still can, and whoever had can take it back. Unticking clears the part's review and verification with it, even a review given before completion that no one else can withdraw. A frozen box stays clickable but never toggles: a click shows the card's locked notice (``showLocked``, from task_status_block.html) instead, saying the task has to be marked not complete first. {% endcomment %} {% if s.is_viewer %} {% if s.done %} {% else %} {# Opens the evidence dialog (task_evidence_modal.html), which marks it. #} {% endif %} {% elif s.can_mark_done %} {% elif marks_locked %} {% else %} {% endif %}
