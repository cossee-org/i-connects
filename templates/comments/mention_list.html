{% comment %} The @ list of a comment box, and the tags it has picked. Included inside a form carrying x-data="mentionBox()" (base.html), right after the textarea's wrapper; that wrapper must be ``relative`` for the list to drop down beneath the box. mention_data is {"candidates": [{id, name}], "selected": [...]}: who can be tagged, and who already is (an edit). Each pick posts one mentioned_user_ids; the server keeps only those whose @Name is still in the text, so a name deleted from the box after it was picked tags no one. The list follows the ARIA combobox pattern: the textarea owns it (aria-controls, aria-expanded, aria-activedescendant are set from mentionBox), arrows move, Enter or Tab picks, Escape closes. {% endcomment %} {{ mention_data|json_script }}
