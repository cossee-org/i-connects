On init Alpine restates it in the browser's zone and locale, reading the epoch seconds off the element so no date string has to survive parsing. ``datetime`` carries the machine-readable instant either way. Alpine picks this up inside HTMX-swapped content too, which is how the side pane's own toggles work, so a comment appended to a thread converts as well as one rendered with the page. {% endcomment %} {{ at|date:"M j, Y g:i A" }}
