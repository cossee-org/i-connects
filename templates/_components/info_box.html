{% comment %} An (i) button and the box it opens — drawn by the ``{% infobox %}`` tag (apps/tasks/templatetags/task_tags.py), which hands over ``label`` (the button's accessible name) and ``content`` (what the tag wraps). For a page title's (i) with a plain-text note, see _components/info_popover.html; this one takes markup and Alpine bindings, and works inside dialogs. The box opens below the button, from the nearest ``relative`` ancestor, and closes on a second click, a click outside or Escape. Escape is kept from reaching an enclosing while the box is open, so it closes the box and not the dialog. No id on the element x-show hides: HTMX puts an id'd element's old style back after a swap, which would open it. {% endcomment %} {{ content }}
